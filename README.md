# 柚月小手机 · 设备联动桥

在现有 SillyTavern 和原版柚月小手机中使用角色联动。酒馆插件负责互动；安卓设备桥只负责本机蓝牙。不需要 Intiface，也不替换你的酒馆。

**0.4.0-preview 是待真机验收的预览版。当前只有 Cachito「诱桃·偷欢 Pro AI版」协议 ID 36 驱动。旧定制宿主的该协议和角色联动已有用户实测，本次独立设备桥尚未完成手机端端到端测试。**

## 你需要什么

- 安卓 8.0 或更高版本、支持 BLE 广播的手机。
- SillyTavern 1.18+，以及原版 [柚月小手机](https://github.com/gaigai315/yuzuki-phone)。
- 本项目的安卓 APK 和第三方酒馆插件。
- 酒馆页面所在浏览器/客户端须允许访问本机 `http://127.0.0.1:8765`。不同 WebView、HTTPS 页面和浏览器的本地网络策略不同，不能保证仅凭版本号即可兼容。

## 安装

1. 保留原版柚月小手机。如果装过旧的「柚月小手机 · 偷欢 Pro」扩展，先禁用它，避免同时运行两套控制器。
2. 安装本项目的安卓设备桥 APK。预览包采用开发签名，供测试，不是商店正式版。
3. 在设备桥允许“附近设备”和通知权限。填写你实际打开的酒馆地址，保存；默认强度上限为 30。
4. 点“开启酒馆桥接”，再点“复制配对密钥”。离开助手页面时手动调试会停止，后台桥接会继续运行。
5. 在酒馆扩展面板中安装 `https://github.com/yanyu612/yuzuki-device-bridge.git`。若使用本地 ZIP，解压后直接包含 `manifest.json` 的文件夹应放到酒馆的第三方扩展目录；不要与旧扩展同时启用。
6. 刷新酒馆，点击屏幕侧边的拉片。在“连接与配对”中选择“独立安卓设备桥”，粘贴密钥并保存。
7. 先确认状态显示设备桥就绪，再决定是否开启“角色自动控制”。角色控制默认关闭；手动操作、立即停止及通知栏停止均可用。

源码与扩展安装地址：[yanyu612/yuzuki-device-bridge](https://github.com/yanyu612/yuzuki-device-bridge)。安卓预览 APK 从仓库 Releases 下载。请先阅读预览版验证边界。

## 支持与边界

| 项目 | 状态 |
| --- | --- |
| Cachito ID 36 的指令编码 | 复用已确认的广播协议；公开测试仅含合成控制端编号 |
| 角色稳定、波浪、脉冲、停止 | 复用原有联动；节奏由同一执行器的强度变化产生 |
| 本次独立桥配对与原生截止 | 有自动化测试；待安卓真机验收 |
| 旧版定制宿主 | 可手动选择原生接口兼容模式，不会自动使用旧接口代替独立桥测试 |
| 其他品牌/型号 | 未适配，不能根据同品牌或相似蓝牙名称推定支持 |
| 日志自动分析、自动生成新型号驱动 | 本版未实现 |

广播没有设备回执。界面上的“已发送”只表示手机接受/发送了请求，不能代替实物动作确认。角色节奏在网页端生成，网页暂停可能暂停变档；原生桥保留原始截止时间，不因变档续期。

这里的配对密钥只连接“酒馆插件与本机设备桥”。当前广播协议没有已确认的单台设备定向机制，附近多台同协议设备可能同时响应；它不等于硬件配对。协议说明见 [docs/PROTOCOL.md](docs/PROTOCOL.md)。

## 配对、隐私和停止

- 每台手机首次安装生成自己的配对密钥和控制端随机编号。仓库不包含任何人的实际配对资料。
- 插件密钥仅存当前浏览器 localStorage，不进入酒馆的扩展设置同步；共享同一浏览器的脚本仍处于相同信任边界。
- 安卓桥仅监听 IPv4 回环地址；网页来源须与助手保存的酒馆地址一致，所有真实接口均核验密钥。
- 设备桥不接收聊天、角色卡或模型 API 信息，不使用云服务。重置密钥会使旧配对失效，并先请求停止。
- 手动调试最多 30 秒；每条角色控制指令最多 30 分钟，变档只能缩短当前期限。服务用活动期间的唤醒锁维持本地截止计时。
- 通知栏常驻“立即停止”。关闭桥接会先发送停止，再关闭服务。安卓系统强杀进程、蓝牙关闭或撤销权限可能使停止帧无法发出，不能把软件计时器当成硬件断电保证。

## 构建和检查

前端不需要 npm 安装依赖：

```sh
npm test
npm run check
```

安卓构建需要 JDK 17+、Android SDK Platform 36 / Build Tools 36.0.0。SDK 路径在你自己的 `android/local.properties` 或 `ANDROID_HOME` 中配置，不能提交个人路径。

```sh
cd android
sh ./gradlew testDebugUnitTest assembleDebug lintDebug
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。测试用本机 HTTP 假设备处理器，不发送真实蓝牙指令。

Windows PowerShell 中将上一条命令换成 `.\gradlew.bat testDebugUnitTest assembleDebug lintDebug`。
